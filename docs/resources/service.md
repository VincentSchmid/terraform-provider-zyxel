# zyxel_service (Resource)

Manages a reusable Firewall > Protocol service in `firewall_proto`. Reference its native `id` from `zyxel_acl_rule.service_id`. Import by exact name; changes replace the service. Deletion is refused while any ACL references the service because the router can cascade-delete associated ACL rules. Remove dependent ACL rules before replacing a service (a two-stage apply may be necessary). Live writes remain unverified on hardware.

## Example Usage

```terraform
# Addresses are documentation placeholders. Choose an unused ACL position after
# reviewing your router's complete rule table before applying.
resource "zyxel_service" "https" {
  name              = "HTTPS"
  description       = "Secure web"
  protocol          = "tcp"
  source_ports      = "*"
  destination_ports = "443"
}

resource "zyxel_acl_rule" "https" {
  name             = "Allow-HTTPS"
  action           = "accept"
  order            = 10
  source_cidr      = "198.51.100.0/24"
  destination_cidr = "192.0.2.10/32"
  service_id       = zyxel_service.https.id
}

resource "zyxel_service" "ping" {
  name      = "Ping"
  protocol  = "icmp"
  icmp_type = 8
}

resource "zyxel_service" "ping6" {
  name        = "Ping6"
  protocol    = "icmpv6"
  icmpv6_type = 128
}

resource "zyxel_service" "gre" {
  name            = "GRE"
  protocol        = "other"
  protocol_number = 47
}
```

## Schema

### Required

- `name` (String) Exact unique service name; natural identity and import key.
- `protocol` (String) Protocol: `tcp`, `udp`, `icmp`, `icmpv6`, or `other`.

### Optional

- `description` (String) Service description. Defaults to empty. Changes replace the service.
- `destination_ports` (String) TCP/UDP destination ports using `*`, a single port, or an inclusive range. Omit for any. Changes replace the service.
- `icmp_type` (Number) ICMP type, -1 (any) through 143. Only valid for `icmp`; omitted means any. Codes are not filtered.
- `icmpv6_type` (Number) ICMPv6 type, -1 (any) through 143, for example 128 for echo request. Only valid for `icmpv6`; omitted means any. Codes are not filtered.
- `protocol_number` (Number) Required for `other`: IP protocol number 0-255. Use named protocols instead of 1, 6, 17, or 58.
- `source_ports` (String) TCP/UDP source ports: `*` (any), `443` (single), or `443-445` (inclusive range). Omit for any. Changes replace the service.

### Read-Only

- `id` (String) Native router service Iid, suitable for `zyxel_acl_rule.service_id`. Not the display index. Changes when the service is recreated.
- `router_index` (Number) Current display index for diagnostics only; refreshed before deletion.

## Import

Import using the exact service name, not its native ID or display index:

```shell
terraform import zyxel_service.https 'HTTPS'
```

An omitted port selector and `"*"` both mean any port. Imports represent any
ports as omitted; explicit `"*"` values can be added to configuration afterward.
