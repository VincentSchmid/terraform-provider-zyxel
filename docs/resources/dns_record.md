# zyxel_dns_record (Resource)

Manages one local DNS host record (`Network Setting > DNS > DNS Entry`) that maps a host name to an IPv4 address. The router has no verified in-place update operation, so every configurable change replaces the record. Existing records must be imported by host name. Host names are compared without regard to letter case; the router's own entry limit still applies.

The exact `hostname` is the natural identity and import key. It must contain at
least two dot-separated labels and is compared without regard to letter case.
Configuration requires the canonical lowercase form; import accepts any letter
case and stores that canonical form. Several host names may resolve to the same
address, but a host name must be unique. The router's own entry limit (the web UI
offers at most 20 entries) is authoritative.

## Example Usage

```terraform
resource "zyxel_dns_record" "nas" {
  hostname     = "nas.home.arpa"
  ipv4_address = "192.168.1.20"
}
```

## Identity and changes

Existing records must be imported before Terraform manages them; Create never
adopts a matching record. Duplicate matches fail without changing the router.
The computed `router_index` is an observed locator, not the Terraform identity.
Delete reads the table again and resolves the host name to its current index.

Every configurable change replaces the record because in-place updates have not
been verified. Replacement deletes the old record before creating the new one, so
name resolution is interrupted and a failed creation may leave the record absent.
Do not use `create_before_destroy` when retaining the same host name.

The create payload contains only `HostName` and `IPv4Address`, letting the router
choose defaults for settings outside this resource's schema. A client lock
serializes this provider's operations; it cannot coordinate other Terraform
processes or router UI edits.

The implementation is verified against local encrypted mock servers. Live DNS
entry creation and deletion have not been verified on hardware.

## Schema

### Required

- `hostname` (String) Canonical lowercase host name with at least two dot-separated labels, such as `nas.home.arpa`. Each label is 1-63 characters of letters, digits, hyphens, or underscores and starts and ends with a letter or digit. This is the natural identity and import key.
- `ipv4_address` (String) IPv4 address returned for this host name. Changing it replaces the record.

### Read-Only

- `router_index` (Number) Current router list index used only as a locator. It may change when other records are added or removed and is not used as resource identity.

## Import

Import uses the record's host name. Letter case is normalized to lowercase; use
that canonical form in configuration.

```shell
# Import by host name; letter case is normalized to lowercase.
terraform import zyxel_dns_record.nas 'nas.home.arpa'
```

An existing record must be imported before Terraform creates it. Multiple rows
matching the same host name are an error; the provider never chooses one
arbitrarily. Missing records leave state on refresh, and deletion of an already
absent record succeeds.
